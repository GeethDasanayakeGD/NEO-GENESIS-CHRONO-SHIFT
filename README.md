# 🌌 NEO-GENESIS: CHRONO SHIFT

An ultra-advanced, action-packed 2D cyberpunk platformer built entirely in a single, self-contained HTML5 file. Featuring custom neon rendering, time dilation mechanics, procedurally synthesized retro-synthwave audio, and a multi-phase boss battle against **TITAN-X OMEGA**.

## ✨ Features

* **🕒 Chrono-Shift Dilation:** Slow down time on command (`Right-Click` or `F`) to weave through complex enemy bullet hell patterns.
* **🔫 4 Distinct Tactical Weapons:** Switch weapons on the fly (`Q` key or mouse wheel) between Plasma Blaster, Spread Pulse, Homing Missiles, and Quantum Beam.
* **👾 Multi-Phase Boss System:** Survive the drone waves to trigger an epic multi-phase showdown against the AI Overlord **TITAN-X OMEGA**.
* **🎵 Native Web Audio Synthesizer:** Zero external MP3/WAV files! Sound effects and synthwave basslines are synthesized in real-time using the browser's Web Audio API.
* **📱 Cross-Platform Responsive Controls:** 
  * *Desktop:* Fullscreen immersive gameplay with Keyboard (`A/D/W`, `Shift`, `Space`) and Mouse aiming.
  * *Mobile / Tablet:* Custom on-screen virtual joystick and touch action buttons (`DASH`, `JUMP`, `FIRE`, `WPN`, `TIME`).
* **🌟 Cyberpunk Aesthetics:** Dynamic parallax grid backgrounds, screen shake camera physics, glowing neon shaders, and retro scanline overlays.

## 🚀 Quick Start / How to Run

Because this is built as a **Single-File Application**, running it requires zero complex setup or build tools:

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari).
3. Click **INITIALIZE MISSION** and dive into the cyber-grid!

## 🕹️ Controls Guide

| Action | Desktop Controls | Mobile / Touch Controls |
| :--- | :--- | :--- |
| **Move Left / Right** | `A` / `D` or `←` / `→` | On-screen D-Pad Left / Right |
| **Jump / Double Jump** | `W`, `↑`, or `Space` | On-screen `JUMP` button |
| **Neon Dash** | `Shift` (Left or Right) | On-screen `DASH` button |
| **Fire Weapon** | Left-Click / `E` | On-screen `FIRE` button |
| **Switch Weapon** | `Q` key | On-screen `WPN` button |
| **Chrono-Shift Time** | Right-Click / `F` | On-screen `TIME` button |

## 🛠️ Built With

* **HTML5 Canvas API** for high-performance 2D rendering.
* **Vanilla ES6 JavaScript** for game loop, physics engine, particle systems, and AI behaviors.
* **Web Audio API** for real-time procedural sound design and music synthesis.
* **Tailwind CSS** for modern UI panels and layout overlays.
